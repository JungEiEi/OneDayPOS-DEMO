OneDayPOS สำหรับ GitHub Pages

1. สร้าง repository ใหม่บน GitHub แบบ Public
2. แตก zip นี้ แล้วอัปโหลดไฟล์ทั้งหมดไปที่รากของสาขา main
   ต้องเห็น index.html อยู่ที่รากของ repo ไม่ใช่ซ้อนอยู่ในโฟลเดอร์
3. Settings > Pages > Deploy from a branch > Branch: main > Folder: / (root) > Save
4. รอประมาณ 1 นาที แล้วเปิด https://ชื่อผู้ใช้.github.io/ชื่อrepo/

ใช้ได้บน GitHub Pages โดยไม่ต้องกด Publish
ข้อมูลการขาย สต๊อก และผู้ใช้ อยู่บนเบราว์เซอร์ของเครื่องนั้นเครื่องเดียว ไม่ได้รวมกับเครื่องอื่น
