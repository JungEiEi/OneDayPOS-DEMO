# OneDayPOS

ร้านเล็กก็ขายได้สบาย ๆ
ระบบขายหน้าร้านสำหรับคาเฟ่และเบเกอรี่ เปิดแล้วกดขายได้เลย

## เดโมนี้คืออะไร

เป็นมุมให้ลองเล่นก่อนตัดสินใจใช้จริง
ไม่ต้องสมัคร ไม่ต้องเข้าสู่ระบบ เปิดลิงก์แล้วอยู่ที่เคาน์เตอร์ทันที

> ข้อมูลบิล สต๊อก และเมนู ถูกเก็บไว้ในเบราว์เซอร์ของเครื่องนั้นเครื่องเดียว
> เปิดอีกเครื่องจะไม่เห็นของกัน และล้างข้อมูลเบราว์เซอร์แล้วรายการในเครื่องนั้นจะหาย

## ทำอะไรได้บ้าง

- แตะเมนูใส่ตะกร้า แล้วคิดเงินได้ทั้งเงินสด โอน และบัตร
- พิมพ์หรือบันทึกใบเสร็จขนาด 80 มม.
- ดูบิลวันนี้ สรุปสินค้า บิลที่ยกเลิก และเงินที่ต้องนำส่ง
- เช็กสต๊อก รับของเข้า และปรับยอดคงเหลือ
- จัดการเมนู หมวดหมู่ ผู้ใช้ และข้อมูลร้านในหน้าแอดมิน
- ส่งออกหรือนำเข้าข้อมูลเป็นไฟล์ เมื่ออยากย้ายเครื่อง

เมนูตัวอย่างในเดโมเป็นของร้าน **วันเดย์ คาเฟ่** เช่น ข้าวผัดไก่ ครัวซองต์ และชาไทยเย็น แก้ชื่อ ราคา หรือรูปได้เองในหน้าแอดมิน

## เปิดเดโม

1. อัปโหลดไฟล์เว็บไปที่รากของ repository แบบ Public ให้เห็น `index.html` ชั้นบนสุด
2. เปิด GitHub Pages จากสาขา `main` โฟลเดอร์ `/ (root)`
3. เข้าที่ `https://ชื่อผู้ใช้.github.io/ชื่อrepo/`

แถบด้านบนจะบอกว่าเป็นเดโมทดลองใช้ กดขายได้เลย

## เหมาะกับใคร

เหมาะกับร้านเคาน์เตอร์เดียว ที่อยากลองระบบก่อน หรือใช้บนเครื่องเดียวในร้าน
ถ้าร้านมีหลายจุดขายและต้องเห็นสต๊อกกับบิลร่วมกัน เดโมนี้ยังทำแบบนั้นไม่ได้
